# Gaffe Log

- **LLM-managed sequence numbers** — Negotiation runs let the LLM fabricate `seq` inside outbound messages, and the simulator just forwards the value. Because the policy prompt never says “increment monotonically,” GPT‑5 mini reuses earlier numbers (9 ➝ 10 ➝ 4 ➝ 13 ➝ 4). If any downstream analytics ever rely on `seq`, those runs become unreliable. Fix by removing the field from the policy output and assigning it inside the environment so completed runs stay valid.
- **Frozen orientations** — `GridWorld.resolve_moves()` never updates `self.orientation[aid]` after the initial spawn (see `grid.py`, no assignment inside the move loop). Observations always report the spawn-facing direction, and `MsgHere` packets broadcast the same stale orientation for the entire episode. Any logic that depends on teammates’ headings—like estimating intent, inferring front/left, or validating loop breaks—operates on wrong data, so existing negotiation and coordination results are suspect until we track orientation with movement.
- **Message ages never increment** — Every delivered radio packet is stamped with `age=0`, and `build_observation()` clears inboxes without aging prior entries. The policy never sees how old a message is, so all multi-turn negotiation logic we recorded assumes fresh data even when it’s a turn (or more) old. Communication experiments that rely on inbox age are therefore invalid until we implement proper age increments each turn.
- **Missing idle/directional sprites** — The renderer only loads `crewmate_{north,east,south,west}.png`. With no idle frame—and with orientations frozen—we never show standing agents or correct headings. Until we import the full five-sprite set (N/E/S/W/idle) and drive selection from actual movement, every GIF misrepresents agent posture, undermining visual analysis.
