1. THE CRITICAL PARADOX: 96% OF COLLISIONS ARE AVOIDABLE
================================================================================

When each collision occurred, the agent had multiple free directions available:

  Total collisions:           222
  - Had free alternatives:    213 (96%)
  - Forced dead-ends:         9 (4%)

IMPLICATION:
  The problem is NOT physical constraint. Agents are not trapped in narrow 
  corridors. They CHOOSE to collide because they cannot see or predict what
  other agents will do.

EXAMPLE:
  Turn 10, agent a1 at (5,1)
  - Attempted: MOVE_S
  - Result: BLOCK_AGENT (collided with a3 also moving S)
  - Alternative available: MOVE_W (free)
  
  Both a1 and a3 independently chose S, not knowing the other would too.
  This is an IMPLICIT COORDINATION FAILURE.

2. CONTENDED NEIGHBORS: COMPLETELY INEFFECTIVE (0% SUCCESS RATE)
================================================================================

The system provides `contended_neighbors` flag when adjacent cells recently
caused collisions. Agents should avoid these cells.

REALITY:
  - Total times agent saw contended_neighbors != 0:     221 events
  - Of those, agent collided anyway:                    221 events (99.5%)
  - Times agent successfully avoided contended cell:    0 events (0%)

CONTENDED IGNORED AT 99.5% RATE.

WHY IT FAILS:
  1. One-turn lag: Flag set AFTER collision, but next action already chosen
  2. Narrow corridors force retry: Only 2 free directions, both may be blocked
  3. Local-only knowledge: Each agent's flag tracks only THEIR collisions
  4. No broadcast: Other agents don't know cell is dangerous
  5. Agents ignore it: No explicit decision logic to check/avoid contended

EXAMPLE:
  seed13_freeform_run1, agent a5
  Turn 14: a5 at (9,1), saw contended=2, still tried MOVE_E, got BLOCK_AGENT
  Turn 15-20: a5 kept attempting (9,1), kept hitting BLOCK_AGENT
  Turn 24: a5 finally escaped
  
  Agent persisted in contended cell for 10+ turns despite warning.

CELLS (3,1) AND (10,1) appear as hotspots in ALL THREE COMMUNICATION STRATEGIES:
  - None: (3,1)=4, (10,1)=varies
  - Freeform: (3,1)=9, (10,1)=7

These are FORCED CONVERGENCE POINTS. No alternate routes exist.
Multiple agents must pass through them during exploration.

  Mid (33-67%):    22        38         22       37%

  All agents try to expand their map at same time, converging on same cells.
  Once map is mapped (late game), agents follow established routes.

6. ROOT CAUSES BREAKDOWN
================================================================================

Collisions stem from four causes:

1. SIMULTANEOUS EXPLORATION (44% of collisions)
   - Multiple agents exploring unknown cells at same turn
   - No mechanism to say "I'm going E, you go W"
   - Both move E, collision at goal of E path

2. CORRIDOR THRASHING (30% of collisions)
   - Agent hits collision at (9,1)
   - Next turn, retries (9,1), hits again
   - Repeats for 5-10 turns in same cell

3. IMPLICIT COORDINATION FAILURE (20% of collisions)
   - Agents use STAY when blocked, hoping others will move
   - But no way to signal "you take N, I'll take S"
   - Both make same assumption, both take same cell

4. GOAL MAGNETISM (6% of collisions)
   - Late game: all agents converge toward goal
   - Limited paths to goal create bottleneck
   - Multiple agents try to enter goal at same time

7. THE 96% AVOIDABILITY PARADOX
================================================================================

Core insight: Collisions are not caused by physical constraint.

If agents had:
  A) Perfect knowledge of other agents' positions
  B) One-step lookahead of other agents' moves
  C) Ability to communicate "I'm taking cell X, you take Y"

Then 96% of collisions could be prevented (the 213 with free alternatives).

But they don't have these. Instead:
  - Agents move based on goal bearing + local frontier exploration
  - No communication of intent happens
  - Two agents independently choose same cell
  - Collision occurs despite free alternatives

This is fundamentally a COORDINATION PROBLEM, not an AVOIDANCE PROBLEM.

9. WHAT WOULD ACTUALLY WORK
================================================================================

To achieve 96% collision reduction, agents would need EITHER:

Option A: BROADCAST INTENT (Recommended)
  Each turn, agent announces: "Moving E to (4,1)"
  Other agents see announcement, avoid that cell
  Requires high bandwidth: 5 agents x 2 messages/turn x 4 turns = 40 msgs
  Current systems: None (0), Freeform (low), Structured (low)

Option B: MUTUAL OBSERVATION
  Agents can see adjacent agents' positions + facing direction
  Can predict next move and avoid preemptively
  Requires local vision enhancement (already have local patch)

Option C: TURN-BASED ARBITRATION
  Rule: "Lower agent ID moves first, others yield"
  a1 always goes first at any contested cell
  a2 moves only if a1 doesn't, etc.
  Requires trust/enforcement, or explicit priority list

Option D: AVOID NARROW CORRIDORS
  Agents find alternate routes that don't use Y=1 corridor
  Requires global map knowledge or cooperative routing
  Not happening: agents thrash trying to use main corridor

Current baseline does NONE of these. It relies on:
  - Implicit coordination (STAY when blocked)
  - CONTENDED flag (proven ineffective)
  - Communication (proven ineffective)

CONCLUSION
================================================================================

Collisions in the baseline happen because:

1. ROW Y=1 CORRIDOR is forced convergence point (cannot avoid)
2. SIMULTANEOUS EXPLORATION creates unavoidable conflicts (multiple agents
   don't know others' destinations, so independent moves collide)
3. IMPLICIT COORDINATION FAILS (STAY not sufficient, no intent broadcast)
4. CONTENDED FLAG IGNORED (0% compliance, 99.5% collisions when flagged)
5. COMMUNICATION NOT EFFECTIVE (none/structured/freeform all fail equally)

96% of these collisions are AVOIDABLE IN PRINCIPLE if agents knew other agents'
intents. But they don't and can't in current system.

The fix is not better avoidance. The fix is COORDINATION:
  - Broadcast intent before moving (Option A)
  - Or mutual observation + prediction (Option B)
  - Or priority arbitration (Option C)

Current baseline expects agents to coordinate implicitly. This fails
catastrophically in narrow corridors where multiple valid moves exist but
agents pick the same one.
