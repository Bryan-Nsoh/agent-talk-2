# Gaffe Log (resolved 2025-11-06)

- **LLM-managed sequence numbers** — Negotiation runs let the LLM fabricate `seq` inside outbound messages, and the simulator just forwards the value. Because the policy prompt never says “increment monotonically,” GPT‑5 mini reuses earlier numbers (9 ➝ 10 ➝ 4 ➝ 13 ➝ 4). If any downstream analytics ever rely on `seq`, those runs become unreliable. _Fixed: environment now owns the counter and injects it before delivery._
- **Frozen orientations** — `GridWorld.resolve_moves()` never updates `self.orientation[aid]` after the initial spawn (see `grid.py`, no assignment inside the move loop). Observations always report the spawn-facing direction, and `MsgHere` packets broadcast the same stale orientation for the entire episode. Any logic that depends on teammates’ headings—like estimating intent, inferring front/left, or validating loop breaks—operates on wrong data. _Fixed: orientations update whenever an agent moves; STAY retains the previous facing._
- **Message ages never increment** — Every delivered radio packet was stamped with `age=0`, and `build_observation()` cleared inboxes without aging prior entries. The policy never saw how old a message was, so all multi-turn negotiation logic assumed fresh data even when it was stale. _Fixed: inbox ages advance once per turn before observations are built._
- **Missing idle/directional sprites** — The renderer only loaded `crewmate_{north,east,south,west}.png`. With no idle frame—and with orientations frozen—the GIFs misrepresented agent posture. _Fixed: added a fifth idle sprite and choose it whenever the last action is `STAY`._
